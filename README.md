# miniguia-notebooklm-DIO
Projeto desenvolvido como desafio prático da plataforma DIO, utilizando o Google NotebookLM para construir uma base de conhecimento especializada sobre George S. Patton Jr. O foco é aplicar curadoria de fontes, aprendizagem ativa e engenharia de prompts para reconstruir seu modelo de raciocínio estratégico.
